# Sinvo — Offline Shop Manager

Offline-first shop inventory, billing and business management web app.

Features: products, stock ledger, low-stock alerts, sales/billing, printable invoices, purchases, customers/credit, expenses, reports, search/filtering, JSON backup/restore, PWA offline cache, and optional Google Sheets backup through Apps Script.

Normal operation needs no internet. See apps-script/Code.gs for Google Sheets backup setup.
